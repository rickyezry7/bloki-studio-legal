Kebijakan Privasi Bloki Studio

Berlaku sejak 3 November 2026.

Siapa yang memakai aplikasi ini

Bloki Studio adalah aplikasi pribadi yang hanya berjalan di komputer pemilik channel YouTube Bloki Hoki. Tidak ada pengguna lain.

Data Google yang diakses

Dengan izin pemilik akun, Bloki Studio memakai YouTube Data API dan YouTube Analytics API untuk:

  • membaca statistik channel dan video (views, subscriber, durasi tonton) untuk dashboard target;
  • mengunggah video Shorts ke channel milik pemilik akun.

Penyimpanan dan berbagi data

Token akses dan data statistik disimpan hanya di komputer pemilik. Data tidak dikirim ke server lain, tidak dijual, dan tidak dibagikan ke pihak ketiga. Data hanya dipakai untuk fungsi di atas.

Penggunaan dan pemindahan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Akses bisa dicabut kapan saja lewat tombol Putuskan di Bloki Studio atau di pengaturan izin akun Google. Setelah dicabut, token di komputer pemilik dihapus.
